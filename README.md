# BuahWira《果刃寻贤》

BuahWira《果刃寻贤》是一款以马六甲王朝显赫人物与历史知识为主题的华语／Bahasa Melayu 双语网页教育游戏。学生阅读题目与完整选项后，以鼠标或触屏滑动切开代表答案的水果。

## 游戏特色

- 华语与 Bahasa Melayu 双语切换
- 水果切割答题玩法，支持鼠标与触屏
- 三个关卡、错题重试及连续错误判定
- 总音量设置、背景音乐与正式水果切割音效
- 关卡结算页面与最终学习成果页面
- 面向横屏桌面、平板及手机的响应式界面

## 学习内容

游戏涵盖马六甲王朝的显赫人物、苏丹、宰相与海军统帅的职责、传统社会结构，以及历史人物的贡献与领导价值。

## 操作方式

1. 选择语言并开始游戏。
2. 阅读题目与四张答案卡。
3. 等待 A、B、C、D 水果从下方飞出。
4. 鼠标拖动或触屏滑动，切中正确答案水果。
5. 避开陷阱；错题会重新出现，掌握本关全部题目后进入下一关。

## 运行方式

- 访问 GitHub Pages 的游戏链接；或
- 下载项目后直接打开根目录的 `index.html`；或
- 在项目根目录启动任意静态服务器，例如：`python -m http.server 8000`。
